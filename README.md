# Butterfly Game

A simple browser game where the player clicks flying butterflies before the timer reaches zero.

## How to play

1. Open `index.html` in a browser.
2. Press **Start Game**.
3. Click the butterflies to score points.
4. Try to beat your best score before the 30-second timer ends.

## Files

- `index.html` – page structure
- `style.css` – styling and butterfly visuals
- `script.js` – game logic and animations

## Run locally

You can simply open `index.html` directly in a browser, or serve it with a small local server:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000
